# Does the live 15:40 night signal use extended-hours high/low? (2026-10-08)

Verdict: NOT CONFIRMED. The live high/low behave as regular-hours; the audit's "false positives" are a price-timing artifact. No code change, no branch.

## Code path
`marketdata.schwab_rows` (swingtrader/daily/marketdata.py ~157-159): price = `regular.regularMarketLastPrice`; high/low = `quote.highPrice/lowPrice`. Schwab's `regular` block carries only last/size/change/tradeTime, so there is no regular-market high/low field to switch to. `quote.totalVolume` DOES include extended hours (live/all-hours SIP volume median 0.998 vs 1.03 vs RTH, n 44), so the quote's volume is session-wide, but its range is not.

## Evidence (71 logged live night decisions 09-24..10-07, Alpaca SIP raw minutes 04:00-15:42 ET)
IBS recomputed with the logged live price against (a) RTH range (09:30+) and (b) extended range (04:00+):
- 43/71 names have a pre-market extreme outside the RTH range. Among the 22 where it moves IBS by >0.005, live IBS matches RTH within 0.002 in 17 and extended in 0 of 22.
- Median abs error: RTH 0.000, extended 0.004. Exact (<0.005): RTH 76%, extended 54%.
- The audit's 4 mismatches: BIAF (live .0147 = RTH .0147 exactly; extended .0090), ZCSH (.0883 = RTH exactly), USDE (.0968 = RTH exactly) all match RTH with the logged price; the audit's SIP IBS (e.g. BIAF .162) used the last 15:41 minute-bar close instead of the live last trade. CNXC (.0083/.0126 live vs .021/.037 RTH) is the only true residual: live IBS lower, i.e. a lower low than SIP RTH minutes show, not an extended-hours low (no pre-market low below RTH low; only highs differ).
- All 11 residual mismatches have live IBS BELOW the SIP value (live price at/near a fresh low printed after the last minute bar), a timing effect, and in the qualifying direction.
